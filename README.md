# Cory Carmen Portfolio Website

A personal portfolio website that showcases Cory Carmen's transition from 25 years
in commercial diving and fishing into software development. The site combines a
personal story, project case studies, live interactive widgets, and — as its
newest feature — an **AI assistant that answers questions about Cory**.

**Live site:** [cory-carmen.vercel.app](https://cory-carmen.vercel.app)

## Overview

The site is a static website (HTML, CSS, JavaScript, Bootstrap 5) hosted on Vercel,
with one small serverless function powering the AI assistant. It highlights Cory's
background, development journey, technical skills, current learning focus, and
recent projects, and it deploys automatically on every push to `main`.

## Key Features

- **"Chat with Cory" AI assistant** — a floating chat widget that answers visitor
  questions about Cory, grounded only in his own documents, with streaming answers,
  source citations, and honest "I don't have that" refusals. See
  [README-chatbot.md](README-chatbot.md) for the full writeup.
- Downloadable resume (PDF) from the hero and contact sections
- Expanded hero, About, and career transition story with strong personal branding
- Grouped technical skills with interactive skill popups
- Currently Learning section for active growth areas
- Project showcase cards for all five projects, with live links where available
- CircuitStream graduation credential badge (verifiable on Credly)
- Sidebar widgets: Portfolio Snapshot stats, Project Spotlight, GitHub Activity,
  Now Building, Quote of the Day, Weather, and a News feed
- Contact form with validation (Web3Forms) and a GitHub/LinkedIn profile links
- Dark mode that follows the system theme, with a saved manual override
- Responsive layout for desktop, tablet, and mobile

## The AI Assistant

The "Chat with Cory" widget is the standout feature and a portfolio piece in its
own right. A visitor asks a question and gets a streaming, grounded answer built
only from Cory's own documents (`data/knowledge/*.md`), generated by Claude through
a Vercel serverless function.

- **Frontend:** vanilla JS widget (`js/chat-widget.js`), styled to match the site
  in light and dark mode.
- **Backend:** `api/chat.js` (Vercel serverless function) with the grounding logic
  in `lib/chat-core.js`, using the Anthropic Claude API.
- **Quality:** a tested question set and scoring script live in `eval/`.

Full details, design decisions, and run instructions are in
[README-chatbot.md](README-chatbot.md).

## Development Setup

The static site can be viewed on its own, and the AI assistant needs Node.

1. Clone the repository and open it in VS Code.
2. **View the static site only:** open with Live Server (or any static server).
3. **Run the site with the AI assistant locally:**
   - `npm install`
   - Copy `.env.example` to `.env` and add your `ANTHROPIC_API_KEY`
   - `npm run dev`, then open `http://localhost:3000`
   - `npm run eval` runs the assistant's quality checks

See [README-chatbot.md](README-chatbot.md) for more on the assistant.

## Deployment

The site is hosted on Vercel and **auto-deploys on every push to `main`**.

- A build step (`scripts/generate-config.js`) rebuilds `js/config.local.js` from
  Vercel environment variables at deploy time, so private contact details and API
  keys are never committed.
- The AI assistant reads `ANTHROPIC_API_KEY` from Vercel's environment variables
  (server-side only).

## Local Private Setup

The project separates public-safe values from local private values.

- Public-safe defaults live directly in `js/script.js`.
- `js/config.local.js` holds private local values and is ignored by Git.
- On Vercel, `js/config.local.js` is generated at build time from environment
  variables (see Deployment above).

To show your direct contact details and the weather widget locally, create
`js/config.local.js`:

```js
window.PORTFOLIO_LOCAL_CONFIG = {
    contact: {
        email: 'your-email@example.com',
        phone: '(555) 555-5555',
        location: 'Your City, Province, Country'
    },
    visibility: {
        showEmail: true,
        showPhone: true,
        showLocation: true,
        enableContactForm: true,
        enableWeatherWidget: true
    },
    weather: {
        apiKey: 'your-openweathermap-api-key',
        defaultLocationQuery: 'Nanaimo,CA',
        defaultLocationLabel: 'Nanaimo, BC',
        units: 'metric'
    }
};
```

Without that local file, the public version hides direct contact details and
keeps the contact form and weather widget disabled.
